# Awaaz 🎙️

**Awaaz** is a modern Hindi/English digital reading platform for stories, news and ideas.

The platform is designed around a simple idea:

> **Read when you want. Listen when you want.**

---

## ✨ Features

### 📖 Stories, News & Ideas
- Hindi and English content
- Story, News, Ideas, History and other categories
- Clean editorial reading experience
- Latest published stories appear automatically

### 🔊 Listen to Stories
- Read articles through browser text-to-speech
- Hindi and English language support
- Voice selection where available on the device
- Multiple playback speeds
- Long stories are split into smaller speech chunks for better reliability

### 🔐 Firebase Authentication
- Email/password authentication
- User-based access
- Admin and Editor roles
- Protected Admin Studio

### 📝 Admin Studio
Admins can:
- Create posts
- Edit posts
- Delete posts
- Publish posts
- Save drafts
- Manage article metadata
- Upload cover images

### ☁️ Cloudinary
Cover images can be uploaded directly to Cloudinary.

### 🔥 Firestore
Published content is stored in Firebase Firestore and automatically loaded on the public website.

---

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript (ES Modules)
- Firebase Authentication
- Firebase Firestore
- Cloudinary
- Web Speech API
